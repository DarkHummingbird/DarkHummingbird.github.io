# 我的个人网站

中文个人主页，包含作品展示、个人介绍和随笔阅读，支持手机访问。

网站地址：https://darkhummingbird.github.io/

## 修改内容

- `index.html`：页面介绍、作品名称、导航和联系方式。
- `style.css`：配色、排版与响应式布局。
- `script.js`：作品详情和随笔内容。

个人介绍、作品与文章当前包含明确标记的示例内容，联系方式待填写。
图片通过 Unsplash 在线加载。

## 本地预览

在本目录运行 `python3 -m http.server 4173`，访问 http://localhost:4173。

GitHub Pages 使用 main 分支的根目录发布。推送修改后会自动更新。
